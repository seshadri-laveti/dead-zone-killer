# Contributing

1. Open an issue describing the change, hardware, and reproducible steps.
2. Keep radio settings and pin maps explicit; never assume all LoRa boards use the same wiring.
3. Add a test or bench procedure for changes to packet parsing, retry behavior, alert handling, or telemetry.
4. Label simulated data clearly.
5. Never publish credentials, personal data, or private telemetry logs.
6. Do not make safety-critical performance claims without measured evidence.
